## 1. 四层数据及查看边界

| 层 | 来源/用途 | 是否允许调提示和阈值 |
|---|---|---|
| Legacy | 150 条英语源历史输出、既有患者级诊断 | 可用于研究背景；不当作新方法独立测试 |
| Dev-v3 | 现有原生 20 篇，按新 schema 重建参考 | 是；全部开发迭代留存 |
| Calibration-additional | 若需新语言/文献类型的开发样本，先指定为 calibration | 是；一旦用于查错永远不进入最终 test |
| Test-v3 | 新收集、未用于本项目调试、与前三层无已知来源/病例组交叉 | 否；运行前封存清单、代码与分析规则 |

“未查看”指未用于本研究调参/选择方法，不代表基础模型训练语料中不存在该文献。获取时必须做元数据和解析完整性检查；该检查不看任何被测方法结果。作者既有阅读/策展经历也记录在 exposure ledger，不能仅靠发布日期晚就称无污染。

## 2. 收集与纳入流程

1. 盘点可获取来源，先固定目标疾病、语言、文献类型、年份范围和查询模板。资源仍未定；未填这些字段前不称正式纳入。
2. 保留搜索时间、数据库、query、去重前数量、全文可得性和排除原因。按与性能无关的规则处理重复和不可读材料。
3. 建立 publication group：PDF SHA-256、DOI/题名、译本/预印本关系、共享病例系列和已知家族；可疑关系标记，宁可保留同组敏感性分析，不假定不同 PDF 即独立。
4. 语言以正文实际语言和比例记录，语言识别器仅辅助；无法确认的标 unknown。英语摘要/附录保留并标记，双语文献不自动排除。
5. 文献类型至少标 case report/case series/review/research/other；长度、OCR、表格分别记录。语言和类型过多导致稀疏时减少预声明分层，不能强行声称每层有充分统计功效。
6. 只允许基于冻结前的来源/任务资格排除。超过模型上下文、OCR 困难或参考稀疏的处理规则必须事先固定；测试方法失败不移除文献。

`source_manifest` 最少包含 document_id、publication_group_id、language、disease_scope、type、acquisition_id、original_file_hash、input_text_hash、parser_version、length、ocr_flag、exposure_status、split、eligibility、exclusion_reason。没有 DOI 用稳定本地 ID，不编造 DOI。

## 3. 新版银标准

三个参考模型独立读取同一冻结全文窗口与新目录，输出原子事实、作用域、极性和来源。模型独立请求，不见系统输出或彼此答案。语法错误和不可定位引句按冻结规则拒收，拒收记录保留。

合并候选后进行支持及等价投票。主参考要求至少两票支持，同字段/极性/作用域可对齐，组内每对等价均满足两票；不以传递闭包把非等价值强行合并。所有参考阶段完成并签名封存后，才能开始 test 方法运行。

主任务计入明确阳性与明确否定事实；未报告不是事实。文献背景与个体观察分开，病例数/变异频率等数值保留单位和分母。无法明确区分病例时标作用域 unresolved，并按预声明任务规则记录，而非生成伪病例 ID。

三份标注完成但均无事实可以形成空参考；这不证明文献真实无事实。技术失败不能冒充空参考。参考未能完成的来源在被测推理前单独列为 reference_failed，不进入冻结可评分集合；公开语言/类型分布和失败原因，不能看过方法输出再决定纳入。

模型标识可从已验证的 Claude/Gemini/DeepSeek 组合开始可用性探针，但下一轮的精确请求/返回标识、参数和服务路径必须重新冻结。旧 API 别名不是不可变模型权重证明。

## 4. 评分对象与匹配

主预测集合为方法按自身预定策略输出的事实集；M/B2 都使用完整 accepted 策略。另报全部候选，以观察提取覆盖和门控损失。每篇参考集合固定，所有方法 TP+FN 相同。

匹配需要 field、polarity、source-supported scope 和原子值完整等价；一对一最大二分图匹配，重复值不能重复计 TP。作用域对齐只在评分阶段匿名完成，参考病例键不提供给提取器。匹配器采用相同规则且保留判断票和边，不能按方法单独放宽。

不完全相同但规范化等价的 HGVS、单位等用冻结规则；有歧义时留票裁决。禁止同侧配对混入跨侧匹配；编号域与输入哈希必须校验。部分表型集合重叠不算一个完整原子事实的正确匹配。

```text
TP = 最大一对一匹配数
FP = 预测数 − TP
FN = 参考数 − TP
P  = TP / (TP + FP)
R  = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)
```

主 pooled F1 跨全部文献汇总 TP/FP/FN，包括空参考文献上的 FP。零分母的 P/R/F1 报 NA。文献宏平均的主要补充定义限定 `reference_count > 0` 的固定文献集合；空参考文献另报输出率/FP 数，不用正确空输出的零分母人为改变平均数。

## 5. 重复层级和主要估计量

每文献每方法建议 R=3 次完整产品运行；R 仍待预算冻结。每次用新的请求、译文和候选，不能把同一缓存响应复制成多个重复。参考固定，重复内的派生消融复用候选是预先声明的控制，不是独立推理。

对每个重复 r，先跨来源组汇总文献计数得到 `F1_m,r`；主要差值为 `Δ = mean_r(F1_M,r − F1_B2,r)`。不能把 R 次结果的并集当一个更强系统，也不能把 R×N 当独立文献数。R=1 时 Δ 退化为单次冻结运行差值。

文献嵌套于 publication group。主区间以来源组为重采样单位：同一轮抽到的组及其所有文献，对所有方法和 R 次运行共同保留；重新算 pooled F1 和 Δ。采用 10,000 次、seed 42 的 95% 百分位区间。该区间条件于实际模型标签及 R 次输出；另报告各重复的 Δ、P/R/F1 范围。R 很小时不声称已精确估计未来 API 调用的变异。

若设计有固定语言层配额，bootstrap 在语言层内按组抽样；跨语言同出版组不得拆开，先按预声明组层归属处理。无法实现有效分层时使用整体组 bootstrap 并公开目标样本组成，不反向调整层权重使结果更好。

## 6. 样本量：先得到配对开发信息，再定 N

当前仅有一个方法的原生输出，不能据它计算 H1 的配对差异方差。**本轮不提供伪精确的“至少需要 N 篇”结论，也不报告已达到 80% power。**

按以下方案执行 prospective planning：

1. P2 在 Dev-v3 上完成 M/B2 配对结果，保留每组参考数、各方法 TP/FP、匹配重叠、重复运行和成本。若新测试语言/疾病明显不同，需指定额外 calibration 数据，不能假定 Rett 方差适用所有领域。
2. 用可接受成本与实际意义制定 SESOI，记录理由；不直接把最好的开发差异当预期效应。可以绘制绝对 F1 差值 0.03/0.05/0.08 的**敏感性情景**，这些仅是规划网格，不是已有临床重要性阈值。
3. 对独立来源组数 N=40/60/80/100/120/160 做候选网格；这不是纳入承诺或功效结论。根据开发组结构模拟联合 TP/FP/参考数，保持 `0≤TP≤reference_count` 和方法配对相关性；效应情景通过明确记录的联合捕获概率/错误计数模型校准，不直接给 F1 任意加常数。
4. 原假设情景使两方法可交换；备择情景包含开发效果收缩、零效应、SESOI 和较弱效应，并增加长文/语言组成及参考漏标敏感性。分布/相关性参数、假设及模型拟合来源全留存。
5. 用最终主分析相同的组重采样检验构造区间，至少 5,000 次外层模拟，报告拒绝概率及 Wilson Monte Carlo 区间，并检查零效应下假阳性率。若为节省计算使用较少内层重采样，必须在边界 N 用最终 10,000 次设置复核后冻结样本量。
6. 默认规划目标为双侧 α=0.05、power 0.80；同时给 0.90 的成本情景及预期区间宽度。SESOI 或合理联合数据模型无法确定时，使用精度/可行性驱动的样本量说明，明确不作充分功效承诺。
7. 来源获取/解析/参考构建损失只用冻结前实际比例规划预备来源；预算估算计入失败。模型失败是评价结果，不可通过删除样本使“有效 N”变大。只进行冻结前的样本量调整，不按 test 显著性追加样本。

产物：`sample_size_plan.json`、`power_sensitivity.csv`、功效/精度图、成本随 N 曲线、参数来源说明。它们目前尚未生成统计结果；只有完成开发配对数据及参数选择后才执行模拟。

## 7. 随机化和调用时段控制

所有文献接受所有方法，不把不同语言分配给不同方法。随机化的是文献处理顺序、各方法调用顺序及外部评判的匿名顺序。

推荐固定种子：样本/来源排序 20260925、方法顺序 20260926、匿名评判 20260927、bootstrap 42。种子控制本地编排，不代表 API 确定性或供应商支持 seed 参数。

每个重复轮次内，按冻结 metadata 分层打散文献。真实调度针对唯一提议/翻译/审核 DAG：只在依赖已满足的节点之间按种子随机排队，并在文献批次内平衡 OO/OT 分支的先后，记录被资源约束改变的实际顺序。F_OO_R0/F_OT_R0 是派生单元，实际没有对应 API 调用；不能用 8 个结果行的名义排列冒充真实调用顺序随机化。

运行表至少记录 run_id、document_id、publication_group_id、repeat_id、method_id、node_id、dependency_ids、planned_order、actual_start/end、provider、model、worker、attempt。OO/OT 在同一近邻批次完成，不先跑完所有 M 再隔天跑 B2；候选提议使用无历史的新上下文。

翻译在同一文献/重复内共享，推理缓存是否启用及命中情况全部记录。比较独立运行成本时各方法均承担其所需翻译/共享节点的完整成本，实际账单另报去重后总额。缓存后的 wall time 不能冒称每个方法的冷启动时延。

仅允许共享事前指定且输入、提示、参数完全相同的同一逻辑节点，例如同一重复的原语第一轮。缓存身份包含 document/repeat/node/proposal_round/request_hash；OO 的第二轮即使请求正文相同也必须独立调用，不能复用第一轮响应。不同 repeat 不共享产品/翻译调用。外部审计对完全相同主张的复用另计，不作为产品重复。

## 8. 失败、服务漂移与续跑

- 建议同请求最多 3 次，300 秒 timeout；这是待开发探针验证的统一设计值，最终各模型支持参数以实际请求为准。429/传输错误遵循相同有界重试，费用全计入。
- 未完成/截断/编号非法响应拒收；冻结的无损 JSON 容器转换可以用，不能修补标签内容。优先保留最早有效结果，成功 schema 缓存必须直接复用并检查请求哈希。
- 文献所有提取节点失败时输出集为空，主评分为 TP=0、FP=0、FN=参考数；部分节点完成保留其有效结果，标 partial。不得只报告成功案例。
- 评测面板调用失败与产品失败分开。无法得出支持判断记 unassessable；匹配票不足时保留未决边并报告乐观/保守匹配界限，不能默默当成确定错误。主要评分要求对齐完整；无法完成时主分析标 incomplete，不宣称正式结论。
- 别名/返回模型标识变化、供应商停服、配额变更或协议哈希漂移触发暂停该配对批次。保存原尝试；决定冻结新版本重跑完整受影响配对批次，或将其列为技术未完成，不能单独重跑得分较差方法。
- 达到预算上限时停止新请求，保留所有计划未执行任务。预算未执行造成的试验不完整单列；不能把因项目资金停止而从未运行的剩余方法伪装为模型失败并计算优劣。

## 9. 次要分析与多重比较

H1 为唯一确认性主要比较，95% 区间跨 0 则不宣称优势。H2 的两个审核效应及交互、H3 策略分析默认探索性，报告效应与区间，不把未经校正的多个显著结果作确认性发现；若升级为确认性次要族，须在冻结前指定 Holm 校正族并据其设计功效。

固定敏感性分析：三票一致参考（重新分组，不保证主参考子集）；按不同参考模型家族留出重建的面板依赖敏感性；只计可定位引句；known duplicate/related group 另一分组边界；unassessable 的保守分母；按显式阳性/否定分别报告。留出标签构建模型不等于建立独立人工金标准。

不做已观察效果的 post-hoc power。语言和疾病分层来自同一最终运行，样本小则明确描述性；不把语言排序解释为模型能力排序，不把聚类 bootstrap 当成消除训练污染、标签错误或临床误差。

## 10. 冻结顺序与论文表图

```text
任务/目录/新 schema → 开发参考与工程验证 → 配对开发比较
→ 样本量/预算/方法/BIO/阈值定稿 → test 来源清单与代码冻结
→ test 参考完成并封存 → 产品矩阵/重复运行
→ 匿名外部审计与完整对齐 → 单一评分入口 → 所有表图
```

拟交付主表：T1 来源/独立组/分层；T2 全方法 P/R/F1/支持度/成本；T3 2×2 审核效应；T4 定位/支持/身份与队列；补充表保留全部文献、字段、失败、预算和运行重复。拟交付图：流程与状态、配对差异区间、成本–效果、门控策略点/合法风险–覆盖、预定义错误分布。历史结果另表标 legacy，不再出现 pending recomputation 的主分析。
