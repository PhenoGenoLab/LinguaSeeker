## 本版先固定的决策

- 独立统计单位为来源组；每篇文献运行全部方法。重复推理、字段和模型票不算新的独立文献。
- 主要对照为 `M`（原语+译语）对 `B2`（同预算双次原语），两者使用相同审核和接纳策略。
- 主要终点为预先定义 accepted 输出相对于固定银标准的 pooled F1 配对差异；候选全集、支持度、覆盖和成本同时报告。
- 采用 8 个方法评测单元；其中 2 个“无审核”单元复用预先固定的候选池。门控回放另标为离线策略分析，不冒充新推理实验。
- 提取器的内部审核与外部评测面板分开；引用定位率不能代替语义支持，银标准未匹配不能自动等同于幻觉。
- 建议正式运行重复 3 次，但次数及资源上限尚未授权/冻结；若只运行 1 次，结论范围相应缩小。
- 唯一主要比较、10,000 次配对来源组 bootstrap、seed 42、95% 区间；其余比较遵循详细统计分析计划。
- 样本量在新方法配对开发实验之后计算；本轮不声称 20 篇或任意固定篇数具有足够统计功效。

## A. 核心目标与成功标准

要检验的是：同模型和预算下，双语言路径与原文核验是否改善证据覆盖和支持可靠性。没有人工资源时，结果只能表述为银标准符合度或模型判定支持度。

主要比较为完整双轨系统对同预算双次原语系统的配对原子事实 F1 差值；同时强制报告 P、R、每文献 FP、模型判定支持率和成本，防止用单项最优掩盖其他损失。只有预先指定比较的区间和成本/风险结果共同支持，才声称该条件下存在收益；结果不支持时保留负结果。

门控另在相同候选池上比较：固定展示数量或匹配覆盖率时，不受支持输出是否减少。阈值和展示上限只用开发集选择。原语/翻译带来的候选变化与门控选择收益分开解释。

## B. 数据、资格和污染边界

1. 历史 150 条、已分析的原生 20 篇及既有七例均作为已暴露开发材料。不能随机重新分出其中一部分就声称是从未查看的测试集。
2. 另建未查看的原生文献清单，记录查询、日期、来源、语言、疾病、文献类型、长度、纳入/排除原因。新范围与语言配额在任何测试输出出现前固定，不为改善某语言结果调整纳入。
3. 按同出版物、内容重复/译本、共享病例系列/已知家族建组。PDF 哈希、DOI/题名只解决部分重复问题，无法确认的依赖标为未知。整个来源组只进入一个 split；条件允许时增加未用于开发的疾病层。
4. 样本量以开发数据的文献级配对差异和预定最小有意义效应/区间宽度模拟确定，并公开预算约束；不能宣称凑够某个文献数就具备统计功效。语言层太小只给描述统计。
5. 保留原文英语摘要/附录并标记。总体指标针对实际输入材料；若要归因到原生非英语内容，应另预定片段语言标签的分析，未可靠标记时不作隔离语言效应的结论。
6. 每篇保留原始 PDF、实际文本、解析器/OCR 配置、字符偏移映射和解析失败。困难来源不能因模型结果不佳被排除。全文范围和解析质量对所有方法相同。

## C. 先固定事实契约，再修改算法

维持全目录覆盖作为开发目标：对现有 143 个非策展字段逐项明确“原文明示事实”的允许值类型、作用域和来源要求。若任务范围需要调整，必须在新测试前发布新 catalog 和映射表，全部方法共用；不能以本次 23 字段较高的事后 F1 作为缩窄范围的理由。

稳定跨模块契约用具名 Pydantic/dataclass，放 `contracts.py`。至少包括：

| 维度 | 要求 |
|---|---|
| 身份 | document_id、source_hash、field_id、fact_id；来源身份与模型猜测分离 |
| 内容 | 单个原子值、规范化值及规范化规则版本；多值用数组，不用分号串隐式编码 |
| 作用域 | 文档背景/研究队列/明确病例/实验对象；病例或变异身份未知时不得猜测 |
| 证据 | 原文跨度集合及偏移、原文/译文块映射；记录位置是否可恢复 |
| 语义 | 显式阳性、显式阴性、未报告、不确定；作者断言与独立科学结论分开 |
| 派生值 | HPO/术语映射和生物学推断另层存储，说明输入与映射依据 |
| 决策 | proposed、accepted、review_required、rejected；每个拒绝/待审原因可见 |
| 运行 | 模型/提示/阶段/父候选、请求和响应收据、stage 输入可见范围 |

`unknown_not_reported` 是未报告状态，不能自动成为 `found` 正向事实。病例中出现某变异不能默认证明 gene–disease causative。原文未报告的 HPO 编码不能冒充来源事实。实体规范化不补出缺失等位基因、患者关系或亲子关系。

新 schema 若改变原子粒度，必须重新生成该版本的开发参考和对齐，不用旧复合值结果与新原子值结果拼接。v2 的封存参考、341 个预测及主 F1 保持原样。

同一字段允许多个有来源的值；候选竞争按实体/病例作用域和事实身份定义，不能每个文档–字段只保留一个最高分值。不同病例的基因型、同一病例的多个表型分别保留；只有真正重复的事实才去重。

## D. 接纳规则和保留状态

定义 `L(e)` 为原文跨度可定位，`S(e)` 为语义支持判断，`I(e)` 为实体/病例归属满足该字段要求，`X(e)` 为未解决冲突。拟采用：

```text
accepted(e) = positive_or_explicit_negative_fact(e)
              AND L(e) AND S(e)=supported AND I(e)=satisfied
              AND NOT X(e)
```

其中 `S(e)` 的模型判定不称为事实真值；定位成功也不能推出 `S(e)`。文档级字段不强求患者 ID，但病例级关系必须有相应作用域证据。明确违反规则的候选拒绝；无法判定的进入待审；未报告作为字段状态记录。三类队列分别计数、分别展示，留档不代表接纳。

外部目标只允许部署时已知的用户查询/提供信息，留存其来源。不得读取 gold keys、gold worksheet、expected 值或评测匹配器输出。额外实体信息对所有方法完全一致。旧 DB-ready allowlist 不可进入新测试。

门控单元验收包括：合法引句但错误值、相同变异不同病例、否定句误作阳性、缺少亲子确认却输出确认 de novo、空引句占位、多个冲突候选、无结果文献。原文坐标和支持判断各自有失败记录。

## E. 输入与语言路径

全文窗口必须提供覆盖清单，所有正文字符要么进入窗口、要么属于预声明的无正文元数据排除；不得静默只留首尾。窗口重叠去重不跨病例合并事实。表格、图注和 OCR 保留来源类型与可定位程度。

翻译按带 ID 的原文块进行，保留原文→译文映射及独立 MT 模型/提示/参数。翻译侧返回的值必须映射回原文核验。译文中的新数字、变异或关系不能仅因翻译流畅被接受。翻译成本计入总预算。

不预设把所有字段一次塞入一个超长提示。可按字段家族和窗口调度，但所有方法读取的原文范围、字段定义和预算上限相同；覆盖、字段家族路由及预算耗尽造成的失败必须计入结果。

## F. 同预算基线与消融矩阵

| ID | 方法 | 目的 |
|---|---|---|
| B0 | 原语单次 schema prompting | 可解释的低成本参照，保留其较低成本，不冒称完全预算匹配 |
| B1 | 全文分块/检索 + schema 抽取 + 自审核 | 较强任务匹配基线；与完整系统采用相同抽取/审核模型角色及可用输入 |
| B2 | 原语两次独立提议 + 相同融合/审核/门控 | 主要资源对照，控制多次调用和候选数量 |
| B3 | 翻译单轨 + 相同审核/门控，回到原文核验 | 分离翻译路径贡献 |
| M | 原语+翻译双轨 + 融合/审核/门控 | 待评方法 |
| Bio | 生医实体/变异工具 + 明示 schema adapter + 相同来源检查 | 覆盖任务匹配生医比较；不能把工具的 NER/检索输出直接当完整事实抽取 |

Bio 的候选实现可从 PubTator 3.0 等现有资源开始核查；先确定其输入语言、接口/模型版本、许可和适配可行性。需要翻译时使用同一冻结 MT 并记成本。全任务 adapter 与工具原生支持字段子任务分开报告，不能用不相容输出空间作优越性结论。具体可运行实现必须在测试前固定，不能在看到测试结果后择优选择。

M 对照消融：去翻译轨（对应 B1 或严格复用相同原语子流程）、去语义审核、去来源位置约束、去选择性接纳。每个消融写出实际复用的候选、stage 和调用预算；至少检验语言路径×语义审核的交互。去门控/核验的候选仅用于离线评测，不自动发布到临床证据视图。

“匹配预算”同时固定总 token/金额上限、全文可见范围、模型角色和允许重试。翻译和审核不得免费忽略。无法精确相等时报告实际成本–效果曲线，在重叠预算区域比较，不能只按调用次数相同宣称公平。超时与预算耗尽按预声明规则计入主分析，另报技术成功率。

## G. 银标准与来源支持评价

参考仍可采用 Claude/Gemini/DeepSeek 的独立生成、候选并集、原文引句与多数票；具体模型标识和参数在下一轮执行前冻结。参考构建只看原文和固定任务规范，不看被测方法身份或输出。分歧、拒收、单票事实和投票完整保留，参考先封存再执行测试方法。

输出到参考的匹配和输出引句支持判断使用匿名化候选，隐藏方法名称及门控决定；随机/哈希呈现顺序，禁止凭哪个方法得分高选择某次模型响应。来源支持检查针对完整主张而非仅检查词汇重叠，至少区分 supported、contradicted、insufficient、unassessable，并单列归属错误。

同一模型面板参与标签与评判会相关，需在报告中公开。可做三票一致、轮换留出模型/模型家族、引句要求等敏感性分析；这些方法均不能把银标准变成人工 gold。模型一致率或 κ 只描述相应条件集合，不代表人类标注可靠性。

为避免遗漏所有模型均未提出的事实，明确参考是模型发现的正向候选并集，其召回分母不保证穷尽。若无人工资源，不声称已测得相对于全文真实全部事实的绝对召回。

可另建确定性合成压力测试：交换病例归属、修改数值/变异、改变否定、让引句取自错误文档等。只对构造过程能确定违反条件的样例定义预期失败；不能随意换数值就假定原文绝不支持。此测试验证拒错行为，不并入真实文献性能或临床精度。

## H. 指标与分母

| 指标 | 定义与必须披露内容 |
|---|---|
| 原子事实 P/R/F1 | 同字段、同作用域、一对一匹配；错误值计 FP+FN；同一参考集下所有方法 TP+FN 恒定 |
| 跨度恢复率 | 可定位跨度的事实数/输出事实数；候选与 accepted 两层都报，零分母记 NA |
| 模型判定支持率 | 被面板判为 supported 的完整主张数/全部被审计主张数；contradicted/insufficient/unassessable 分开，不能删未知后抬高比例 |
| 身份/病例归属 | 分析有关系标签的样本；未建立标签时记未评，文档值集 F1 不能代替病例正确率 |
| 选择性接纳 | 全候选到 accepted/review/rejected 的流转、接受覆盖率、相对银标准错误率；模型风险–覆盖曲线不是临床安全曲线 |
| 语言互补 | 双轨新增匹配事实、原语已有事实丢失、新增不支持输出；与同语双次控制配对比较 |
| 负担代理 | accepted/待审/拒绝数、FP/文献、每 100 展示项的模型支持项；无人工计时不转成分钟或工作量减少百分比 |
| 成本/可靠性 | 请求/返回模型、token、金额或可计算计价依据、耗时、重试、完成率；保留失败的意向评测 |

主报告给微平均与文献宏平均；按来源组做配对 bootstrap，同一重采样同时取所有方法输出。语言、疾病、类型、长度分层仅使用同一冻结最终运行。主比较预指定，其余多重比较用事前规则或明确标为探索性，不只挑显著者报告。

默认数值实现采用 10,000 次配对来源组 bootstrap、seed 42，报告 95% 百分位区间及实际组数；正式 protocol 固定后不因区间是否跨零更换统计方法。来源组太少时应报告估计不稳定，不能靠增加重采样次数弥补独立样本不足。

重复运行次数在预算 manifest 固定；若只能运行一次，区间解释为给定模型输出/标签下的样本变异。若要声称模型稳定性，应对完整配对方法重复相同样本并报告运行间变异，不能以文献 bootstrap 代替重复推理。

## I. 最小复现包

每个 study 保留：source/parse/catalog/split manifests；Git 提交及 dirty 状态、实际源码哈希和归档；锁文件与运行环境；各模型/MT 的请求与服务返回标识；system/user prompt 原文与版本哈希；实际发出的解码参数；每阶段可见输入/输出；配额/超时/重试及版本选择规则；所有原始候选和门控原因；参考/投票/对齐/计分器版本；生成全部表图的单一入口。

时间顺序必须能复核：开发修改完成 → 协议/测试清单冻结 → 参考封存 → 方法运行 → 匿名评判/对齐 → 全表导出。更改标签定义、窗口、提示或模型均生成新版本；测试运行中的序列化修正单独留存并说明发生时点。

## J. 按依赖推进与验收

| 阶段 | 工作 | 验收条件 |
|---|---|---|
| P0：数据契约 | 原子值、未报告状态、原文明示/派生解释、决策三队列 | 独立回归用例覆盖，不修改冻结 v2；字段目录对所有方法一致 |
| P1：覆盖与来源 | 完整窗口、表格/OCR 标记、原文偏移、翻译块映射 | 输入覆盖清单无静默缺口；错误原文/病例引用被检测；技术失败明确留存 |
| P2：开发比较 | 在已暴露 20 篇上运行 B0/B1/B2/B3/M 及核心消融，确认 Bio adapter | 所有结果标为开发；预算/字段/作用域对齐；不根据最终测试调阈值 |
| P3：测试冻结 | 新文献、独立来源组、模型标签、配置/预算与主要比较 | 不含已暴露文献及其已知重复组；所有必需 manifest 完整；无 gold-derived gate |
