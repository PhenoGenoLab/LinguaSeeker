## 目的与边界

本工件从统一多维证据矩阵 R5 生成按来源语言分层的描述性统计，用于检查已保存探索性候选的证据宽度。它不是确认性分析、优效检验、总体参数估计或语言因果效应估计；候选为便利样本，来源访问层级、同记录英文暴露和患者身份去重状态并不均衡。

英文基线和多语种探索均可复用本地 `lit-acquisition` 实现（`/data/yangzs/Projects/01_Platform/05_lit-acquisition`，已登记 commit `14e3dbfd07f1a5e7fbc1257c7f9fea37e29dca40`），也可从 GitHub `https://github.com/lanshi17/lit-acquisition` 取得同一版本。复用该检索层不改变本工件的探索性性质，也不替代确认性检索的访问覆盖、原始响应、双审和独立仲裁门禁。

- 输入矩阵：[`multidimensional_evidence_matrix_r5_unified.json`](../../benchmark/experiments/acmg_multilingual/discovery_20261116/multidimensional_evidence_matrix_r5_unified.json)

脚本只统计矩阵中的候选数、观察患者单位、证据维度计数和覆盖比例，并重新求和确认性端点。它不把摘要-only、访问未决、等位基因级对应或英文来源改写成语言阴性，也不把观察单位写入确认性分母。

## 解释限制

1. 中文样本包含大型队列，患者单位不能与候选文章数互换，也不能在未去重时跨语言相加。
2. 英文适配器 readiness 的全文访问覆盖仍未达 B2 门槛；访问失败和原始响应缺失不能编码为英文阴性。
3. 同记录英文摘要、英文来源、摘要-only 记录和等位基因级对应可能使表面上的语言差异消失或产生错觉。
4. 语言独有事实簇由各候选审计和仲裁账本维护，本表不从维度布尔值反推语言增量。
5. 若要回答“总体上是否增加更多证据”，仍需按已冻结的 1,933 题框、A2 来源宇宙、B2 样本与 D1 预算完成确认性检索，并在缺失/MNAR、全文访问、双审和独立仲裁门禁通过后再进行预注册统计。
