# npj 原生多语言银标准验证

**Status:** completed; working files for human review
**Created:** 2026-09-22
**Scope:** 当前 LinguaSeeker 原生非英语输入的字段抽取；多模型银标准。

用户确认没有独立人工金标准，授权以多模型投票模拟核对。该设计只能测量与模型共识的符合程度，不代表人工金标准精度或临床效用。

## 预先固定的设计

1. 纳入现有 48 家族清单中全部 20 个非英语来源：中文 8、日文 3、俄文 3、韩文 2，葡萄牙语、西班牙语、法语、土耳其语各 1。按源 PDF 聚类；不根据结果排除样本。单一疾病领域及语言样本不平衡限制外推。
2. 冻结本地原始 PDF、实际输入 UTF-8 文本与 SHA-256。19 份使用 PDF 文本层，1 份扫描 PDF 使用保留 OCR。记录解析质量与文档类型；不能把本地哈希绑定称为出版社独立认证。原文自然包含的英文摘要不删除，因此本实验不能单独量化语言因素。
3. 使用当前产品目录的 143 个非策展字段。银标准标注基于原文中明确出现的正向事实，禁止由常识推断未报告的 HGVS、亲子关系、频率、HPO 或 ACMG 结论。分析单位是文档–字段–值集合，不是患者级关联正确率。
4. Claude Sonnet 4.5（`claude-sonnet-4-5-20250929`）、Gemini 2.5 Pro、DeepSeek V3.2 独立提取并提供可定位原文引句；不接触被测系统输出。候选并集由三模型逐项支持/等价性投票，至少 2/3 支持构成主银标准，3/3 为敏感性分析。保留全部争议标签和原始投票，避免只展示一致项目。
5. 当前被测系统使用既有配置的 gpt-5-mini/gpt-5、broad 模式、原文单轨、完整字段目录以及现有审核/来源检查。作为一次新配置实验，不追加进旧 150 条历史结果，也不据此证明双轨或翻译增益。不给系统银标准或目标变异答案。
6. 冻结银标准后，用不含方法名称的编号对齐候选值；三模型多数同意的同字段等价边经一对一最大匹配计数 TP。未匹配预测为 FP，未匹配银标准为 FN，错误值同时产生 FP/FN。另报成功率、预测数量、争议比例、逐语言/逐字段结果；按文档聚类给探索性区间。
7. 记录模型请求与服务返回标识、提示词、参数、响应、代码提交和实际源码哈希。模型供应商别名与模型间误差相关性仍是限制；模型投票不是独立人类审查。

## 工作节点与验收

- 输入与配置冻结 → 20 份 PDF、语言和目录清单可重查。
- 投票与计分代码 → 测试覆盖少数票、无效原文引句、跨字段匹配、重复计分、非传递等价和输入漂移。
- 真实模型运行 → 每个结果有实际 API 响应与配置收据；失败重试保留，不用空文件冒充完成。
- 汇总与复审 → 主结果和一致性敏感性分析可离线复算，表述明确银标准边界。
- 文档归档及主目录回写 → 更新模块指南、progress/lesson 和论文研究边界。

## 输入校准记录（被测系统运行前）

首批参考标注暴露 PDF `sort=True` 将双栏逐行交错，真实引句因插入另一栏文字而无法定位。已在原始 PDF 中确认 `sort=False` 的内容流顺序保留连续段落；v1 作为未评分校准包保留，明确未运行被测系统。v2 统一采用内容流顺序，并启用三模型均通过探针的 JSON-object 响应模式。该修正基于输入完整性和结构化输出检查，不基于被测系统表现。

## 参考生成格式修正（被测系统运行前）

部分 Gemini 响应为完整 JSON 事实数组或单元素对象数组；部分 Claude 响应因引句双引号未转义而不是合法 JSON。修正后的读取器只允许无损容器转换：事实数组包装为 `facts`，或解包含已知键的单元素对象数组。损坏 JSON、未完成响应和来源引句不作修补。对未完成调用按编号读取最早可接受的既有完整响应，保留原始响应、失败记录、解析版本与接受的尝试编号；否则继续同请求重试。已完成标注不替换。断点续跑按响应和失败文件的最大编号递增，以免复用纯传输失败的编号。

2026-09-22：22 项离线测试通过，当前模块语句覆盖率 95%。覆盖保存/续跑、拒绝截断输出、引用定位、完整输入切块、三模型参考集封存、实际 LangChain 回调、全流程汇总和冻结文件漂移检查。各阶段启动/续跑保留独立源码快照。此时仍未运行被测系统。

续跑发现 `rett_007`、`rett_081` 的 Claude 响应及长日文报告的部分 Gemini 窗口反复缺少引句内部双引号转义。对于至少三次失败且含 JSON 语法错误的调用，单独在 `serialization-v3/` 留存强化单行 JSON 与 `\u0022` 转义示例的提示及新响应。重新调用同一标注模型，任务、输入和字段不变；不对损坏响应做标签内容修补。此变更发生在任何被测系统推理之前，不以性能选择提示。

长日文报告包含 PDF 文本层遗留的字符串内控制字符（例如 `Pec\x01a`）。读取器允许 JSON 字符串内原样控制字符（`strict=False`），保留其精确值，再执行原文定位；不删除或猜测缺失字母。语法结构损坏仍拒绝。窗口调用改为共享全局信号量，并行处理互不依赖的窗口；提示内容、窗口顺序去重和 6 个请求的并发上限不变。上述修正均有回归测试和阶段源码快照。
